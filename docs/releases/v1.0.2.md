## MM1-BLACK v1.0.2

On-device firmware updates for a sealed tape: Join an access point, then
**Check** / **Install**. USB UART stays factory / recovery only.

### Added

- **Firmware notice** on SETUP → WiFi (and About): new version, up to date,
  or could not reach updates. The top Wi-Fi icon turns amber when an update
  is waiting.
- After Join, Check runs in the background so the clock keeps moving.
- **Install** refuses battery below 20% and only runs after Check finds a
  newer release. Progress shows as *Installing… N%*.
- A good boot confirms the new slot (rollback if the image does not start).
- Pages installer can send the same `.bin` over Wi-Fi to `/update`, with
  USB UART as fallback (no chip / MAC details on the page).

### Fixed

- Join no longer uses `WIFI_STA` on P4 (that path could blank the MIPI
  panel). Same AP+STA mode as the phone AP.
- Check no longer blocks the UI on a short TCP probe to GitHub. Public DNS
  is set after Join when DHCP leaves DNS empty.
- Battery percent uses the P4 ADC millivolt reading (was stuck near 25%).

### Install

1. Open [Install MM1-BLACK](https://verlab.github.io/mm1-black/) (Chrome / Edge).
2. **Wi-Fi:** Join an AP on the tape, enter the address from SETUP → WiFi
   (or `192.168.4.1` on the MM1 access point), then Install.
3. **USB UART:** connect the cable, pick **P4**, then Install.
4. On a tape that already runs this release: **SETUP → WiFi → Join**, wait
   for the firmware notice, then **Install** if a newer tag appears.

**Assets:** `MM1-BLACK-mm1_p4-v1.0.2.bin`
