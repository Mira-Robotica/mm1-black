## MM1-BLACK v1.0.0

First **ESP32-P4** production target (Waveshare 4.3" MIPI + C6 radio) alongside the
existing **CYD** ESP32 firmware.

### Added

- **ESP32-P4 board** (`env:mm1_p4`): ST7701 display, GT911, BNO086, laser UART,
  dual OTA partitions, SAP6 BLE via ESP-Hosted C6.
- **USB installer** board selector (CYD / P4) at
  [verlab.github.io/mm1-black](https://verlab.github.io/mm1-black/).
- **On-device GitHub OTA**: SETUP → WiFi → **Join** a home/lab AP, then
  **Check** / **Install** from `latest.json` (same files as the USB page).
- **VIEW** tab: plan + extended profile. **Cal** menu: IMU / Laser / Trim / Measure.

### Changed

- Wi-Fi defaults **Off**. SoftAP is optional; prefer Join + GitHub install over
  the device `/update` page.
- Laser **trim** is a single millimetre offset applied to every shot, SENSOR,
  VIEW and BLE (`D = D_laser + trim`).
- Continuous capture plays the capture beep on each recorded shot.

### Install

1. Open [Install MM1-BLACK](https://verlab.github.io/mm1-black/) (Chrome / Edge).
2. Select **CYD** or **P4**, then **v1.0.0**.
3. P4: USB **TO UART** (QinHeng), not OTG. First flash of a blank P4 still needs
   PlatformIO (bootloader + partitions).
4. On the device: **SETUP → WiFi → Join** to check later releases.

**Assets:** `MM1-BLACK-denky32-v1.0.0.bin` · `MM1-BLACK-mm1_p4-v1.0.0.bin`
