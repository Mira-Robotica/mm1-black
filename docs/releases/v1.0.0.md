## MM1-BLACK v1.0.0

First **ESP32-P4** production release (Waveshare 4.3" MIPI + C6 radio).
CYD / denky32 is no longer built or published.

### Added

- **ESP32-P4 board** (`env:mm1_p4`): ST7701 display, GT911, BNO086, laser UART,
  dual OTA partitions, SAP6 BLE via ESP-Hosted C6.
- **USB installer** at
  [verlab.github.io/mm1-black](https://verlab.github.io/mm1-black/)
  (select **P4**).
- **On-device GitHub OTA**: SETUP → WiFi → **Join** a home/lab AP, then
  **Check** / **Install** from `latest.json`.
- **VIEW** tab: plan (azimuth) + profile (inclination). Shots project from the
  current station; three matching command shots move the reference.
- **Cal** menu: IMU / Laser / Trim / Measure.

### Changed

- CI / Release / Pages publish **only** `MM1-BLACK-mm1_p4-*.bin`.
- Wi-Fi defaults **Off**. SoftAP is optional; prefer Join + GitHub install.
- Laser **trim** is a single millimetre offset applied to every shot, SENSOR,
  VIEW and BLE (`D = D_laser + trim`).
- Continuous capture plays the capture beep on each recorded shot.

### Install

1. Open [Install MM1-BLACK](https://verlab.github.io/mm1-black/) (Chrome / Edge).
2. Select **P4**, then **v1.0.0**.
3. USB **TO UART** (QinHeng), not OTG. A blank board still needs a first
   PlatformIO flash (bootloader + partitions).
4. On the device: **SETUP → WiFi → Join** to check later releases.

**Assets:** `MM1-BLACK-mm1_p4-v1.0.0.bin`
