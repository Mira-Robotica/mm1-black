## MM1-BLACK v1.0.7

Improves physical capture-button reliability and expands the P4 working
window for point storage.

### Fixed

- Continuous mode now stops when the second tap arrives during a laser wait.
- Hold 5s Nav is disabled while capturing or while a 2-tap sequence is active.
- Hold 5s Nav uses a distinct sound from normal shot capture.
- P4 RAM point window increased from 100 to 1000 points; older points remain
  available in the active CSV on the SD card.

### Install

1. SETUP → WiFi → Join an access point with internet, then **Check**.
2. If **New firmware v1.0.7** appears, tap **Install** and keep the tape on.
3. USB UART remains factory / recovery:
   [Install MM1-BLACK](https://verlab.github.io/mm1-black/).

**Assets:** `MM1-BLACK-mm1_p4-v1.0.7.bin`
