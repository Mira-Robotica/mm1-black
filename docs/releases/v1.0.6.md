## MM1-BLACK v1.0.6

Makes on-device **Check** / **Install** from GitHub Pages reliable on the
ESP32-P4 + C6 path, and aligns continuous capture with TopoDroid's
close-shot gate.

### Fixed

- HTTPS to Pages: clamp the TCP receive window so Fastly does not overflow
  the C6 during the TLS handshake or a large `.bin` download.
- Install uses one HTTP/1.0 GET into PSRAM (same shape as Check). If the
  stream stalls (~3%), close and Range-resume instead of hanging at a few
  percent.
- WiFi status keeps real failure text (`GitHub TLS …`, `Install short N%`)
  instead of snapping back to *New firmware*.
- Continuous / 1-tap / 2-tap use TopoDroid's 5% 3D close gate; only Hold 5s
  writes Nav x3. Samples never become VIEW legs.

### Install

1. SETUP → WiFi → Join an access point with internet, then **Check**.
2. If **New firmware v1.0.6** appears, tap **Install** and keep the tape on
   (download can take a few minutes).
3. USB UART remains factory / recovery:
   [Install MM1-BLACK](https://verlab.github.io/mm1-black/).

**Assets:** `MM1-BLACK-mm1_p4-v1.0.6.bin`
