## MM1-BLACK v1.0.5

Fixes on-device **Check** against GitHub Pages. v1.0.4 never started the
update task (stack too large for internal RAM), so the tape always showed
*Could not reach updates*.

### Fixed

- OTA worker uses a 32 KB internal-RAM stack (49 KB would not allocate).
- `WiFiClientSecure` lives on the heap, not that stack.
- Check uses HTTP/1.0 for `latest.json` (avoids chunked TLS replies).

### Install

1. SETUP → WiFi → Join an access point with internet, then **Check**.
2. If **New firmware v1.0.5** appears, tap **Install** and keep the tape on.
3. USB UART remains factory / recovery:
   [Install MM1-BLACK](https://verlab.github.io/mm1-black/).

**Assets:** `MM1-BLACK-mm1_p4-v1.0.5.bin`
