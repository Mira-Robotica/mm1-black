## MM1-BLACK v1.0.4

On-device **Check** / **Install** now pulls from GitHub Pages only
(`https://verlab.github.io/mm1-black/`), the same files as the USB installer.
No bench PC or local HTTP server.

### Changed

- Check reads `latest.json` over HTTPS (GitHub Pages IPv4 + TLS).
- Install downloads the release `.bin` in small keep-alive Range slices into
  PSRAM, then writes the inactive OTA slot. A single 2 MB GET was dropping
  the C6 radio and leaving the tape on the old version.
- Status text is ASCII only (the previous ellipsis showed as `[]`).
- A good boot confirms the new slot immediately (avoids a black-screen
  rollback).

### Install

1. Open [Install MM1-BLACK](https://verlab.github.io/mm1-black/) (Chrome / Edge).
2. **On the tape:** SETUP → WiFi → Join an access point with internet, then
   **Check**. If a newer tag appears, **Install** and keep the tape on.
3. **USB UART** (factory / recovery): connect the cable, pick **P4**, then
   Install.

**Assets:** `MM1-BLACK-mm1_p4-v1.0.4.bin`
