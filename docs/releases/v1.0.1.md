## MM1-BLACK v1.0.1

### Fixed

- **Laser capture (1-tap / 2-tap / continuous)**: never reuse the last UART
  reading. After continuous capture, switching to one-tap or two-tap waited on
  a cached frame (still “fresh” for 4 s) and stored the same shot again. All
  three modes now wait for a **new** laser return before recording, and skip
  the point if distance / azimuth / inclination still match the last shot.

### Install

1. Open [Install MM1-BLACK](https://verlab.github.io/mm1-black/) (Chrome / Edge).
2. Select **P4**, then **v1.0.1**.
3. USB **TO UART** (QinHeng), not OTG.
4. On the device: **SETUP → WiFi → Join**, then **Check** / **Install**.

**Assets:** `MM1-BLACK-mm1_p4-v1.0.1.bin`
