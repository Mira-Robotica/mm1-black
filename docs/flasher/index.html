MM1-BLACK · Firmware

Atualize seu equipamento

Instale a versão mais recente por Wi-Fi ou utilize a conexão USB UART. Para instalação por USB, use Chrome ou Edge em um computador.

A instalação por USB requer Google Chrome ou Microsoft Edge em um computador. A instalação por Wi-Fi continua disponível.
Método de instalação
  1. 01 Na MM1-BLACK, abra SETUP → WiFi
  2. 02 Conecte o computador à mesma rede
  3. 03 Localize o equipamento ou informe o endereço
  4. 04 Confirme e instale
  1. 01 Conecte o adaptador USB UART
  2. 02 Feche o monitor serial e a IDE
  3. 03 Selecione a placa e a versão
  4. 04 Use BOOT → RST quando solicitado
Modelo da placa

No modo AP, use 192.168.4.1. Ao ingressar em uma rede, consulte o endereço em SETUP → WiFi.
