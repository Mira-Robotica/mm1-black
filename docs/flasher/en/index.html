MM1-BLACK · Firmware

Update your instrument

Install the latest release over Wi-Fi or use a USB UART connection. USB installation requires Chrome or Edge on a computer.

USB installation requires Google Chrome or Microsoft Edge on a computer. Wi-Fi installation remains available.
Installation method
  1. 01 On MM1-BLACK, open SETUP → WiFi
  2. 02 Connect the computer to the same network
  3. 03 Find the instrument or enter its address
  4. 04 Confirm and install
  1. 01 Connect the USB UART adapter
  2. 02 Close the serial monitor and IDE
  3. 03 Select the board and release
  4. 04 Use BOOT → RST when requested
Board model

In AP mode, use 192.168.4.1. After joining a network, find the address under SETUP → WiFi.
